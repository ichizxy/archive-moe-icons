压缩包娘图标工具

启动：双击本目录的“启动工具.cmd”。

文件分类
工具：程序和 Python 启动脚本。
成品图标\PNG：24 种格式的 1024 像素精细角色图案。
成品图标\ICO：24 个 Windows 图标，每个内含 16、24、32、48、64、128、256 像素。
预览图：整套图标、自动尺寸切换、小尺寸对比与独立改色演示。
配色方案：默认配色 JSON；保存、载入配色时默认打开此目录。
模板素材：无字基础图，工具启动时会自动读取。
生成提示词：制作成品时使用的 imagegen 提示词。
导出图标：单个和批量导出时的默认保存位置。
本地图标缓存：应用脚本生成的图标副本，按内容哈希分目录；应用后请保留此目录。

使用
1. 左侧选择格式，预览区上方默认使用“自动切换（推荐）”。
   同一个 ICO 内，16、24、32、48 像素使用简洁标签，64、128、256 像素使用精细角色。
   Windows 按请求的图标尺寸自动选取，无需手动更换图标；PNG 是单张图像，不会切换。
   还可选择“全部简洁文字”或“全部角色图标”；16～32 像素长标签分成两行。
   右侧可修改标签、主题色，以及角色发色或简洁版点缀色。
2. 发色和包体色可分别设置，也可使用“包体颜色跟随发色”。
3. “导出当前 PNG + ICO”会在选定目录内按 png、ico 分类保存。
4. “批量导出整套 + ZIP”会在选定目录中新建独立输出文件夹，生成 PNG、ICO、预览、配色 JSON 和 ZIP。
5. 可新增格式，并保存和重新载入自己的配色方案。

命令行批量生成
在“工具”目录运行：
python icon_customizer.py --export "..\导出图标\my-icons"

工具离线运行，使用本机 Python、Pillow、NumPy 和 Tkinter。
请保持目录结构完整；程序按自身路径读取素材与默认配色，不依赖终端的当前目录。
应用现成图标：先双击“预览图标替换.cmd”查看目标，再运行“应用文件图标.cmd”。
更新或改色后重新应用，脚本会使用新的图标路径刷新旧缓存。
恢复原图标：双击“恢复原图标.cmd”，恢复首次应用前的配置。
上述脚本仅处理当前已关联到 7-Zip 的格式，在当前用户注册表中写入图标项。
首次备份及每次应用前的会话快照保存在“本地备份”目录。
完整的下载、使用、应用和恢复流程请阅读 README.md。
